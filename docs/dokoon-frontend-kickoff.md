# آماده‌سازی شروع فرانت‌اند دکون

## تصمیم‌های تأییدشده (این گفتگو)
- وب‌اپ PWA (یک کدبیس) + پوسته‌ی اندروید (Capacitor/TWA) برای APK؛ آیفون = PWA. بدون Flutter.
- نقشه: کاربر بین نشان و بلد انتخاب می‌کند؛ اگر یکی کار نکرد، دیگری. (لایه‌ی `MapProvider`)
- درگاه: واسط (زیبال یا زرین‌پال؛ هنوز نهایی نشده) پشت لایه‌ی `PaymentProvider`.
- انتشار: بازار + مایکت (اندروید) + دانلود مستقیم از سایت.

## قبل از اولین خط کد (مالک)
1. تأیید نهایی پشته‌ی وب‌اپ + Capacitor (و انتخاب فریم‌ورک UI، پیشنهاد: React + TypeScript + Vite).
2. مجوز فونت Yekan Bakh.
3. دامنه، نام بسته‌ی اندروید (مثلاً `ir.dokoon.customer`)، حساب توسعه‌دهنده در بازار/مایکت.
4. تأیید شرایط و کلید نشان و بلد (وب + اندروید).
5. انتخاب درگاه و گرفتن حساب تست (sandbox).
6. تصمیم دسترسی مهمان و لیست «تصمیم لازم» بک‌اند.
7. داده و دارایی واقعی: لوگو (انجام)، عکس غذاها، شبکه‌های اجتماعی، شماره‌ی پشتیبانی، متن حقوقی.

## کارهای فرانت (ترتیب)
۰. مخزن، TypeScript، lint، CI، i18n فارسی، تعبیه‌ی `dokoon-tokens.css` و فونت.
۱. کلاینت API تولیدشده از `dokoon-openapi.yaml` + mock server (Prism/MSW).
۲. کامپوننت‌های پایه (Button، TextField، Sheet، Dialog، Toast + ۴۰ کامپوننت کتابخانه) با Storybook.
۳. ناوبری (پشته + back دقیق + back اندروید)، تم، پوسته‌ی تب‌ها، لایه‌ی خطا (offline، ۴۰۱، ۵xx).
۴. جریان‌ها به ترتیب: ورود → خانه/رستوران/منو → سبد/تکمیل سفارش (نقدی) → پیگیری → پرداخت آنلاین → حساب و بقیه.
۵. PWA: manifest، service worker، نصب روی آیفون، Web Push. پوسته‌ی Capacitor، push بومی، deep link پرداخت.
۶. تست: واحد، جریان‌ها (Playwright)، دستگاه واقعی اندروید و آیفون (PWA)، دسترس‌پذیری، تم تیره.

## معیار «انجام شد» هر صفحه
مطابق `dokoon-screen-specs.md`: حالت‌های loading/empty/error، تم تیره، RTL و رقم فارسی، back درست، بدون رنگ/فاصله‌ی خارج از توکن، تست در مرورگر واقعی.

## به‌روزرسانی تصمیم‌ها
- پشته‌ی وب‌اپ + Capacitor: تأیید نهایی.
- فونت Yekan Bakh: مجوز تجاری در حین کار از سایت یکانبخت خریده و تأیید می‌شود؛ فعلاً کار با فایل‌های موجود ادامه دارد. **قبل از انتشار عمومی حتماً باید مجوز تمام باشد.**
- دامنه و حساب‌های انتشار: فعلاً لازم نیست؛ تا زمان انتشار/تست پرداخت واقعی عقب می‌افتد.
- محدوده‌ی فعلی: فقط فرانت اپ مشتری؛ اپ‌های رستوران/پیک/ادمین بعداً.
- پیک وجه نقد را دریافت می‌کند (در اسناد اصلاح شد).
