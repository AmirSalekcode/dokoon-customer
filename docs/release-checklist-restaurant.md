## ۵. ظرفیت واقعی (k6 روی staging بک‌اند)

فقط روی staging، با توکن‌های آزمایشی staging (هرگز production):

```
k6 run -e BASE_URL=https://<staging-api>/v1 -e TOKEN=<restaurant token> -e CUSTOMER_TOKEN=<customer token> perf/backend/restaurant.js
```

- بار هدف (D-104): ۵۰۰ اتصال WebSocket هم‌زمان (۳۰ ثانیه بالا آمدن، ۵ دقیقه نگه‌داشتن)، ۲۰۰۰ سفارش در دقیقه (ثبت مشتری + پذیرش رستوران)، ۵۰ کاربر REST پنل.
- قبولی: REST پنل p95 < ۳۰۰ms، ثبت/پذیرش سفارش p95 < ۸۰۰ms، خطا < ۱٪، اتصال WebSocket > ۹۹٪، تأخیر رسیدن رویداد p95 < ۲ ثانیه (`ws_event_delay`؛ ساعت سرور و کلاینت باید با NTP هم‌زمان باشند).
