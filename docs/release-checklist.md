## ۵. روز انتشار

1. همه‌ی ردیف‌های بخش ۱ ✅ و بخش ۲ روی دست‌کم یک گوشی اندروید و یک آیفون پر شده باشد.
2. `version` در `package.json` را بالا ببرید، PR، CI سبز، merge.
3. تگ `vX.Y.Z` روی main. CD: پیش‌بررسی (کلید امضا، `VITE_API_BASE_URL`، قالب تگ) ← بیلد ← امضا ← `apksigner verify` ← انتشار APK در GitHub Release.
   `versionCode = X×10000 + Y×100 + Z` (باید از نسخه‌ی قبلی بزرگ‌تر باشد).
4. همان APK در کافه‌بازار و مایکت و لینک دانلود مستقیم؛ نسخه‌ی وب از image ‏GHCR روی سرور.
5. آزمایش سریع (smoke) روی نسخه‌ی منتشرشده: ورود ← یک سفارش نقدی ← پیگیری.
